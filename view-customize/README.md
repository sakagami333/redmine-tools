# View customize 用の画面改良

[View customize](https://github.com/onozaty/redmine-view-customize) プラグイン(3.6.0)に登録して使う、Redmine 7.0 向けの CSS と JavaScript です。

「管理 → 表示のカスタマイズ → 新しい表示のカスタマイズ」で、ファイルごとに1件ずつ登録します。どれも次の設定で動きます。

| 項目 | 設定値 |
|---|---|
| パスのパターン | 空欄 |
| プロジェクトのパターン | 空欄 |
| 挿入位置 | 全ページのヘッダ |
| 種別 | CSS(`.css`)/ JavaScript(`.js`) |

## ファイル

| ファイル | 種別 | 内容 |
|---|---|---|
| [design.css](design.css) | CSS | 画面全体のデザイン調整(下記) |
| [header-links.js](header-links.js) | JavaScript | ヘッダーに、よく使うカスタムクエリへのリンクを追加する |
| [issue-subject-tooltip.js](issue-subject-tooltip.js) | JavaScript | 省略表示した題名に、マウスを乗せると全文を表示する |
| [external-link-button.js](external-link-button.js) | JavaScript | 編集ツールバーの「Wikiページへのリンク」を、`[文字](URL)` を入れる外部リンクのボタンに置き換える |

## design.css の内容

- 全体の文字サイズ(13px)、一覧の枠線、リンク色、終了したチケットの行を控えめにする
- チケットの表で、題名の列を広く取り、1行で「…」省略する
- ステータスの色分け(トイカラーのチップ:進行中=青、返答待ち=黄、保留=紫、終了=緑、却下=赤)
- コメント(履歴)の枠、Wiki本文のフォントと画像の枠
- 古い方式のアイコン(プラグインなど)が、横に繰り返し表示される問題の修正
- チケット詳細で、親チケットとタイトルを階段状に表示し、トラッカーのアイコン(Font Awesome 6)を付ける

## 環境に合わせて書き換えるところ

- **ステータスの番号**(`status-2` など)と**トラッカーの番号**(`tracker-1` など):「管理 → チケットのステータス / トラッカー」で、各項目のURLの末尾の数字を確認して合わせる。
- **トラッカーのアイコン**:Font Awesome 6(無料版)がページに読み込まれている前提。読み込んでいない場合、その部分は表示されない。
- **header-links.js のクエリ番号**:自分のカスタムクエリの `query_id` に合わせる。

## Redmine 7.0 で気をつけること

- View customize の「全ページのヘッダ」のスクリプトは、Redmine の編集ツールバー(jsToolBar)より**先に**読み込まれる。ツールバーを変える場合は、表示されたあとのボタンを書き換える必要がある(external-link-button.js はこの方式)。
- 7.0 ではヘッダーの構造が変わったため、`#top-menu>ul` のような直下を前提にした指定は効かない(header-links.js は「ヘルプ」のリンクを手がかりにメニューを探す方式)。
