# Redmine チケット一括作成ツール

CSVまたはExcelに書いたチケットを、親子孫の階層ごと、Redmineに一括で作成します。

- 1つのファイルで、ストーリー → 作業区分 → タスクをまとめて作成できる
- **CSV**(`.csv`)と**Excel**(`.xlsx`)のどちらでも読み込める
- トラッカー・優先度・担当者などは、画面に表示される名前のまま書ける
- 題名の頭に、親の題名を自動で付ける(例:`Webサイト刷新:デザイン:ワイヤーフレーム作成`)
- 作成前に「試し実行」で、作成予定の一覧と、入力の間違いを確認できる

## 1. 準備(最初の1回だけ)

### ファイルを置く

WSL2で実行します。ダウンロードフォルダに保存した場合の例です。

```bash
mkdir -p ~/redmine-bulk
cp /mnt/c/Users/<Windowsのユーザー名>/Downloads/redmine_bulk_create.py ~/redmine-bulk/
cp /mnt/c/Users/<Windowsのユーザー名>/Downloads/sample_tickets.xlsx ~/redmine-bulk/
cd ~/redmine-bulk
```

### APIキーを保存する

1. Redmineの右上のユーザーメニュー →「個人設定」を開く
2. 右側の「APIアクセスキー」の「表示」を押し、表示されたキーをコピーする
3. WSL2で次を実行する(`キー` の部分を貼り付けたキーに置き換える)

```bash
echo 'キー' > ~/.redmine_api_key
chmod 600 ~/.redmine_api_key
```

あわせて、Redmineの「管理 → 設定 → API」で「RESTによるWebサービスを有効にする」がオンになっていることを確認してください(管理者の操作が必要です)。

## 2. 入力ファイルの書き方

### Excelで書く(おすすめ)

`sample_tickets.xlsx` をコピーして使います。

- **「チケット」シート**:1行1チケットで入力します。2〜8行目は入力例なので、書き換えるか削除してください。
- **「使い方」シート**:各列の書き方をまとめてあります。
- トラッカーと優先度は、セルを選ぶと一覧から選べます(一覧にない名前も、そのまま入力できます)。
- 開始日・期日は、Excelの日付として入力します(`2027/1/31` などと打てば日付になります)。表示形式は何でも構いません。
- 説明は、セル内の改行(`Alt + Enter`)がそのまま使えます。
- ツールは、「チケット」という名前のシートを読みます。なければ先頭のシートを読みます。別のシートを読むときは `--sheet シート名` を付けます。
- 古い形式の `.xls` は読めません。`.xlsx` で保存してください。

### CSVで書く

```csv
行ID,親,トラッカー,題名,担当者,開始日,期日,優先度,対象バージョン,説明
S1,,ストーリー,Webサイト刷新,,2027-01-05,2027-03-31,高め,,
W1,S1,作業区分,デザイン,,2027-01-05,2027-02-10,,,
T1,W1,タスク,ワイヤーフレーム作成,,2027-01-05,2027-01-20,,,
```

- 「CSV UTF-8」でも「CSV(コンマ区切り)」(Shift_JIS)でも保存できます。
- 日付は `2027-01-31` または `2027/01/31` と書きます。
- 説明の改行は `\n` と書きます。

### 列の一覧(Excel・CSV共通)

| 列 | 必須 | 書き方 |
|---|---|---|
| 行ID | ○ | このファイルの中だけで使う、行の名前。重複しなければ何でもよい(S1、W1、T1 など) |
| 親 | | 親にする行の **行ID**。既存のチケットを親にするときは `#453` のように番号を書く。空欄ならいちばん上の階層 |
| トラッカー | ○ | ストーリー / 作業区分 / タスク など、画面の名前のまま |
| 題名 | ○ | **自分の部分だけ**書く。親の題名と `:` は自動で前に付く |
| 担当者 | | 空欄なら自分。ほかの人は、プロジェクトのメンバーの表示名で書く |
| 開始日・期日 | | 日付。空欄なら未設定 |
| 優先度 | | 通常 / 高め など。空欄なら既定値 |
| ステータス | | 空欄なら既定値(未着手) |
| 対象バージョン | | プロジェクトのバージョン名。空欄なら未設定 |
| カテゴリ | | 空欄なら未設定 |
| 予定工数 | | 時間を数値で(例:`2.5`) |
| 説明 | | 空欄のとき、**タスクだけ**「このタスクのゴール/対応内容まとめ」の雛形が入る |

- 1行目は見出しです。列の並び順は自由で、使わない列は列ごと省いて構いません。
- 見出しは英語(`key, parent, tracker, subject …`)でも書けます。
- 行IDが `#` で始まり、トラッカーが空欄の行は、メモとして読み飛ばします。
- 行IDに数字(1、2、3…)を使うこともできます。親の欄に数字を書くと、まずファイルの中の行IDとして探し、なければ既存のチケット番号として扱います。紛らわしいときは、既存のチケットには `#` を付けてください。

### 題名の付き方

| 入力した題名 | 作成される題名 |
|---|---|
| ストーリー:`Webサイト刷新` | `Webサイト刷新` |
| 作業区分:`デザイン` | `Webサイト刷新:デザイン` |
| タスク:`ワイヤーフレーム作成` | `Webサイト刷新:デザイン:ワイヤーフレーム作成` |

- すでに `親の題名:` から書いている場合は、二重には付けません。
- 親の題名を付けたくないときは、実行時に `--no-prefix` を付けます。

## 3. 実行する

### 試し実行(作成はしない)

```bash
cd ~/redmine-bulk
python3 redmine_bulk_create.py sample_tickets.xlsx --project my-project
```

- `--project` には、プロジェクトの識別子(URLの `/projects/〇〇` の〇〇)を書きます。
- CSVの場合は、ファイル名を `.csv` のものにするだけです。

作成予定の一覧が、階層ごとに字下げして表示されます。入力に問題があれば、作成前にまとめて表示されるので、直してから再度実行してください。

### 本番実行(実際に作成する)

試し実行の内容に問題がなければ、`--apply` を付けて実行します。

```bash
python3 redmine_bulk_create.py sample_tickets.xlsx --project my-project --apply
```

作成したチケットの番号は、画面に表示されるとともに、入力ファイルと同じフォルダに `〇〇.result-日時.csv` として保存されます(行IDとチケット番号の対応表)。

## 4. 途中で失敗したとき

- 作成中にエラーが起きると、**その時点で止まります**。それより前のチケットは作成済みです。
- 作成済みのものは、結果のCSV(`.result-日時.csv`)に記録されています。
- 続きから作るときは、入力ファイルから作成済みの行を削除し、作成済みの親は `#番号` に書き換えてから、もう一度実行してください。

## 補足

- 親チケットの開始日・期日・優先度は、Redmineの設定(「管理 → 設定 → チケットトラッキング」の「親チケットの値の算出方法」)によっては、子チケットから自動で計算され、入力した値は使われません。
- 接続先は既定で `http://localhost:3000` です。変えるときは `--url http://…` を付けます。
- Python 3の標準機能だけで動くので、追加のインストールは不要です(Excelの読み込みも含む)。
