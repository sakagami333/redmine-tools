# Tampermonkey 用スクリプト

ブラウザ拡張機能 [Tampermonkey](https://www.tampermonkey.net/) に登録して使うスクリプトです。

## redmine-new-issue-helper.user.js(新しいチケットの作成補助)

新規チケット作成画面で、次の入力を自動で行います。

- 担当者を自分(「<< 自分 >>」)にする
- 子チケットを作るとき(URLに `issue[parent_issue_id]` があるとき)
  - トラッカーを1階層下にする(ストーリー → 作業区分、作業区分 → タスク)
  - 題名に「親の題名:」を入れる
  - 説明に「このタスクのゴール/対応内容まとめ」の雛形を入れる

トラッカーを変えたあとは、Redmine標準と同じく、そのトラッカー用の項目でフォームが読み直されます(入力した題名・説明は引き継がれます)。

### 環境に合わせて書き換えるところ

- `@match`:Redmine の URL(既定は `http://localhost:3000` と、試験用の `http://localhost:3001`)
- `CHILD_TRACKER`:親のトラッカー名と、子に設定するトラッカー名の対応
- `DESCRIPTION_TEMPLATE`:説明の雛形

### 注意

- チケットテンプレートのプラグイン(redmine_issue_templates)で既定のテンプレートを設定していると、トラッカーの切り替え時に説明欄が上書きされることがあります。
- うまく動かないときは、ブラウザの開発者ツールのコンソールに出る `[チケット作成補助]` の行を確認してください。
